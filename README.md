A simple and user-friendly Todo List mobile application built with **React Native** and **Expo**.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- View total tasks
- Track remaining and completed tasks
- Clean UI with Emerald Green theme
- Custom Poppins fonts

## Technologies Used

- React Native
- Expo
- JavaScript
- Uniwind CSS
- Poppins Font

## Installation

1. Clone the repository:

```bash
git clone https://github.com/IsmailHasanTakid/todolist-takid-16
```

2. Go to the project folder:

```bash
cd YOUR_PROJECT_FOLDER
```

3. Install dependencies:

```bash
npm install
```

4. Start the Expo development server:

```bash
npx expo start
```
